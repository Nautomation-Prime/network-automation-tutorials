# Show Command to Excel

Code for the **[Show Command to Excel](https://www.nautomationprime.io/foundation/tutorials/beginner/netmiko-show-command-to-excel/)** lesson on Nautomation Prime.

> Learn to connect to Cisco devices with Netmiko, execute show commands with TextFSM parsing, and export structured data to Excel using pandas.

Work through the lesson first: it explains every file here. Use this folder to
check your own code, or to skip the typing when you just want to run it.

## Files

| File | From the lesson section |
|---|---|
| `show_version_to_excel.py` | The Complete Script |

## Run it

```bash
python -m venv .venv
source .venv/bin/activate      # Windows PowerShell: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Anything that connects to a device needs a lab. Edit the inventory, testbed or
device details to point at your own lab equipment first, and never run a
tutorial against production.
